# RDPDNet — Python training and inference (PDISAC)

This folder contains the Python side of PDISAC: the **RDPDNet** denoiser and its **adversarial frequency-mixup (AFM)** training, together with the inference bridge that MATLAB calls during evaluation.

## Method

RDPDNet is a lightweight hierarchical latent-variable network that treats range-Doppler (RD) heatmap enhancement as **Bayesian posterior inference**. It is inserted between MF-based RD-map formation and CA-CFAR detection, and it removes the data-induced sidelobes (`Z_rd^ran`) and thermal noise (`N_rd^mf`) introduced by embedding communication bits in the PMCW waveform, while leaving the resolution and the downstream detector untouched.

Training uses three coupled mechanisms:

- a **target-weighted reconstruction** loss against the data-free clean map `Z_rd^prbs`,
- a **hierarchical latent distillation** (the clean-map encoder acts as a teacher, transferred to the noisy-map branch through per-level KL terms; dropped at inference), and
- an **adversarial frequency-mixup (AFM)** minimax, in which a MaskNet synthesizes worst-case interference outside the target support and RDPDNet is hardened against it.

At inference the encoder branch is dropped: `Ẑ_rd = f_den^infer(Z_rd; {Φ_ext, Φ_dec})`, so the denoiser needs **no knowledge of the embedded symbols**.

Python 3.10 (a conda environment is recommended) and the packages in `requirements.txt`:

```bash
conda create -n afm python=3.10 -y

pip install -r requirements.txt
```

## Configuration — one file, one switch

All settings live in **`configs/pdisac_system.json`** (single source of truth). `config_loader.py` builds the config from its `machine_learning` block; the **`PDISAC_SMOKE`** environment variable applies the small `smoke` overrides (dataset, epochs, folds, device):

| mode | command | dataset | output | epochs / folds / device |
|---|---|---|---|---|
| real training | `python -m scripts.train` | `dataset_train.db` | `exps/pdnet_afm` | 200 / 5 / (as configured) |
| smoke test | `PDISAC_SMOKE=1 python -m scripts.train` | `dataset_smoke.db` | `exps/smoke_test` | 2 / 2 / cpu |

`PDISAC_SMOKE` is the **same** switch the MATLAB dataset generator uses, so one variable flips the whole pipeline between the full run and the smoke run. (Paths in the config are repo-root-relative, e.g. `data/dataset_train.db`.)

## Running

All commands are run from this `alg_pdisac/` directory (so `configs`, `data`, `models`, `scripts` resolve as packages).

**Train**

```bash
python -m scripts.train                 # real training → exps/pdnet_afm/checkpoints/best_checkpoint.pth
PDISAC_SMOKE=1 python -m scripts.train    # quick smoke check
```

The checkpoint is written to `exps/<output>/checkpoints/best_checkpoint.pth` (no per-fold subfolder — this is the exact path the MATLAB inference bridge reads).

**Evaluate (optional, Python-side)**

```bash
python -m scripts.test                  # per-fold NMSE of the saved checkpoint
```

**Inference scripts** (`inference_pdnet_mat.py`, `inference_pdnet_mask_mat.py`, `distribution_pdnet_mat.py`) are **not run directly** — they are launched by MATLAB `main9`/`main9b` through the bridge wrappers.

## Link to the MATLAB code (`simulation_matlab/`)

The two sides communicate through files on disk:

1. **Data (MATLAB → Python).** MATLAB `generate_radar_dataset.m` writes `data/dataset_train.db` (or `data/dataset_smoke.db` under `PDISAC_SMOKE`); `scripts/train.py` reads it via `data/read_data.py`.
2. **Checkpoint (Python → MATLAB).** `scripts/train.py` writes `exps/pdnet_afm/checkpoints/best_checkpoint.pth`; MATLAB reads it back through `PDISAC_cfg.inference.checkpoint`.
3. **Inference bridge (MATLAB → Python).** MATLAB `main9`/`main9b` call `inference_run_pdnet*.m`, which launch the three `*_mat.py` scripts (using `PDISAC_cfg.inference.python_executable`) to denoise RD maps, rebuild AFM masks, and export latent distributions.

So the end-to-end loop is:

```
MATLAB generate_radar_dataset  →  data/dataset_train.db
        ↓  (python -m scripts.train)
exps/pdnet_afm/checkpoints/best_checkpoint.pth
        ↓  (MATLAB main9 / main9b via the inference bridge)
sensing evaluation + figures
```
